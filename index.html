LIMITATIONS & PRIVACY

About DeepGuard AI

DeepGuard AI is a static, browser-based demonstration. Files are analyzed in memory and scan records are stored in this browser's localStorage per local profile. No authentication server exists; profile names are not verified identities. External CDN libraries and optional models require network access. No automated signal metric should be treated as sole legal evidence.

MediaPipe/ONNX features are best-effort and model output labels are shown as returned; a generic classification is not a deepfake probability. DSP and stylometry values are measured features, not trained-model confidence.
